# Casino

Небольшое учебное консольное приложение с игрой на ставки. Пользователь задаёт начальный баланс, может просматривать его, сделать ставку или выйти из игры.

## Правила, реализованные в коде

- случайно генерируется целое число от 1 до 20;
- выигрышным считается результат от 18 до 20 включительно;
- при выигрыше выплата рассчитывается по формуле `ставка × (1 + ((2 × число) % 17))`;
- ставка должна быть положительной и не может превышать текущий баланс;
- при нулевом балансе игра завершается.

Ввод начального баланса и ставки проверяется в цикле, поэтому приложение не принимает нечисловые и неположительные значения.

## Запуск

Требуется .NET SDK 10.

```powershell
dotnet run --project .\Casino\CasinoSolution\CasinoSolution\CasinoSolution.csproj
```
