# OrderManager

Учебное консольное приложение для оформления одного заказа. Оно последовательно собирает название товара, количество, имя покупателя и адрес доставки, показывает сводку и запрашивает подтверждение.

## Что реализовано

- проверка, что текстовые поля не пустые;
- проверка положительного целого количества товара;
- повторный запрос при некорректном вводе;
- подтверждение заказа только ответом `y` или `n`;
- вывод ориентировочной даты доставки через три дня от текущей даты.

Заказ моделируется неизменяемой записью `Order`; ввод и подтверждение вынесены в отдельные функции.

## Запуск

Требуется .NET SDK 10.

```powershell
dotnet run --project .\OrderManager\OrderManager\OrderManager.csproj
```
