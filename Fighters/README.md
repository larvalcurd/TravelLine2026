# Fighters

Учебная консольная игра, в которой можно собрать бойцов из выбранных компонентов и запустить пошаговую симуляцию боя между ними.

## Возможности

- создание бойца с выбором расы, класса, оружия и брони;
- просмотр добавленных бойцов;
- бой до последнего выжившего между всеми добавленными бойцами;
- бросок инициативы в каждом раунде;
- случайный множитель урона и критический удар с вероятностью 20 %;
- учёт брони расы и экипировки при получении урона.

Итоговые здоровье, инициатива и базовый урон формируются из характеристик расы, класса и снаряжения. Перед новым боем здоровье всех участников восстанавливается.

## Структура

```text
Fighters/
├── Models/
│   ├── Armors/    # броня
│   ├── Classes/   # классы бойцов
│   ├── Fighters/  # боец и отчёт об атаке
│   ├── Races/     # расы
│   └── Weapons/   # оружие
├── Battle.cs      # сценарий и правила симуляции
├── CharacterCreator.cs
└── CommandHandler.cs
```

Компоненты представлены через интерфейсы (`IRace`, `IFighterClass`, `IWeapon`, `IArmor`), поэтому `Fighter` зависит от абстракций, а не от конкретных вариантов экипировки или расы.

## Команды

```text
add   — создать и добавить бойца
fight — начать бой
list  — показать добавленных бойцов
help  — показать команды
exit  — выйти
```

## Запуск

Требуется .NET SDK 10.

```powershell
dotnet run --project .\Fighters\Fighters\Fighters.csproj
```
