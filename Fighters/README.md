# Fighters

Fighters — консольная игра, в которой можно создавать бойцов и запускать пошаговую симуляцию боя между ними.

## Возможности

- создание бойца с выбором расы, класса, оружия и брони;
- просмотр списка созданных бойцов;
- запуск боя между добавленными бойцами;
- расчет инициативы, атак, урона и победителя.

## Структура проекта

Проект разделен на несколько смысловых частей:

- `Fighters` — основной сценарий приложения: запуск игры, обработка команд, создание персонажей и симуляция боя.
- `Fighters.Models` — доменные модели игры: бойцы, расы, классы, оружие, броня и связанные с ними контракты.
- `Fighters.Models.Fighters` — модели, связанные с бойцами и результатами атаки.
- `Fighters.Models.Races` — доступные расы и их характеристики.
- `Fighters.Models.Classes` — классы бойцов и их боевые особенности.
- `Fighters.Models.Weapons` — оружие и его влияние на урон.
- `Fighters.Models.Armors` — броня и ее влияние на получаемый урон.

## Команды

После запуска игры доступны команды:

```text
add   - добавить бойца
fight - начать бой
list  - показать добавленных бойцов
help  - показать список команд
exit  - выйти из игры
```

## Запуск

```bash
dotnet run --project Fighters
```
