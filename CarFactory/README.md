# CarFactory

Учебное консольное приложение-конфигуратор автомобиля. Пользователь выбирает марку, цвет, тип кузова, двигатель, трансмиссию и расположение руля; приложение проверяет совместимость выбранных компонентов, создаёт автомобиль и выводит его характеристики.

## Что реализовано

- марки `Toyota`, `BMW` и `Tesla`;
- типы кузова, двигателей, трансмиссий и рулевого управления;
- отдельные фабрики брендов, реализующие `ICarFactory`;
- политики совместимости `IBrandCompatibilityPolicy`;
- расчёт максимальной скорости и количества передач;
- интерактивное меню с управлением стрелками, Enter или цифрами.

Для Tesla допускаются только электрический двигатель и автоматическая трансмиссия. Для Toyota запрещена комбинация электродвигателя и механической трансмиссии. Политика BMW в текущей версии не вводит дополнительных ограничений.

## Структура

```text
CarFactory/
├── Components/   # кузова, двигатели, трансмиссии, рулевое управление
├── Domain/       # автомобиль, конфигурация и характеристики
├── Factories/    # фабрики брендов и политики совместимости
├── Services/     # сборка автомобиля и расчёт характеристик
└── UI/           # консольное меню
```

В `CarConfigurator` фабрика выбирается по марке, а политика совместимости выполняется до создания компонентов. `CarPerformanceCalculator` учитывает мощность двигателя, его базовую прибавку к скорости, количество передач и аэродинамический коэффициент кузова.

## Запуск

Требуется .NET SDK 10.

```powershell
dotnet run --project .\CarFactory\CarFactory\CarFactory.csproj
```
